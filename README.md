# Resumo do Lab na DIO

Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na Digital Innovation One (DIO).

## O que eu aprendi

Durante o lab, tive a oportunidade de reforçar e aplicar diversos conceitos fundamentais para o desenvolvimento de projetos no GitHub e no ecossistema de desenvolvimento colaborativo. Entre os principais aprendizados, destaco:

- **Criação e gerenciamento de repositórios no GitHub**: Aprendi a criar um novo repositório, inicializá-lo com um arquivo `README.md` e fazer commits de forma organizada.
- **Documentação com Markdown**: Compreendi a importância de um `README.md` bem escrito para apresentar um projeto, e aprendi a utilizar a sintaxe Markdown para formatar textos.
- **Uso do GitHub como portfólio profissional**: Entendi como manter meus projetos públicos pode ser uma excelente forma de mostrar minhas habilidades e evolução como desenvolvedor(a).
- **Importância da organização e boas práticas**: Vi na prática como um projeto bem estruturado e documentado transmite profissionalismo e facilita a colaboração em equipe.

Esse aprendizado será essencial para minha jornada como desenvolvedor(a), principalmente na hora de compartilhar meus projetos com a comunidade ou com recrutadores.
